Control de versions

En aquest Workshop vam aprendre sobre la importància de tenir un projecte ben guardat, però a més de manera organitzada, centrant-nos en com funcionen les versions i en GitHub i altres exemples que ofereixen un servei on es poden guardar projectes i treballar en paral·lel amb gent des de on sigui.

Així doncs, vam haver de fer dues pràctiques. A la pràctica 1, cada integrant del grup va tenir que crear un document de Google en el que s'havia de continuar una història ja feta que estava a mitjes amb un marge d'entre 50 i 100 paraules. L'objectiu era que el document tingués tres versions diferents, així que per a aconseguir-ho calia escriure tres finals diferents per a la història, o corregir-ne els errors d'algún final, de manera que quedés guardat amb el sistema de versions de Google Docs. Amb això vam aprendre la importància del control de versions ja que, gràcies a això, vam entendre que si a un arxiu es cometen errors es poden restaurar versions anteriors per a arreglar-los.

A la pràctica 2 cada membre del grup es va crear un compte a GitHub i el va tenir que personalitzar, fent canvis com podria ser canviar la foto de perfil, el nom d'usuari i crear un repositori personal i editar-lo per a tenir un Read-me propi. Tot això amb la finalitat de tenir un perfil professional amb el qual realitzar qualsevol tasca que requereixi GitHub al llarg del curs.
