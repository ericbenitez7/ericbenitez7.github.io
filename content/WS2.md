# Control de versions 

A la practica 1 cada integrant del grup va tindre que realitzar un document de google en el que tenia que continuar una historia que ens donaven amb un marge d'entre 50 i 100 paraules, hi havia que escriure tres finals per a l'historia, els quals havia que guardar amb el sistema de versions de google docs. Amb aixo vam aprendre l'importancia del control de versions ja que gracies a aixó, vam veure que si a un arxiu t'equivoques pots restaurar versions anteriors per arreglar-lo.

A la practica 2 cada membre del grup es va crear un compte de GitHub i el va tindre que personalitzar, fent canvis com podria ser cambiar la foto de perfil, el nom d'usuari, crear un repositori personal i personalitzar-lo. Tot aixó amb la finalitat de tenir un perfil amb el qual realitzar qualsevol tasca que requereixi GitHub al llarg del curs.
